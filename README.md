# 逃跑吧少年

逃跑吧少年热点/爆料/攻略/通用兑换码查询插件，从微信公众号搜索实时抓取。

## 安装

在 LoyanBot 插件商店中搜索「逃跑吧少年」即可安装。

## 命令列表

| 命令 | 说明 | 权限 |
|---|---|---|
| `/逃跑热点` | 🔥 最新热点列表 | 所有人 |
| `/逃跑爆料` | ⚡ 版本更新/新活动爆料 | 所有人 |
| `/逃跑攻略 <内容>` | 📖 攻略（可定向搜索） | 所有人 |
| `/逃跑兑换码` | 🎁 最新通用兑换码 | 所有人 |

## 使用

1. 发送 `/逃跑热点` 获取标题列表（带序号）
2. 回复序号（如 `1`）查看该条完整正文
3. 兑换码列表直接显示疑似码，也可输序号进正文找码

## 特点

- ⏱️ 列表 30 分钟缓存、正文 10 分钟缓存，自动刷新保证时效
- 📄 正文抓取：标题列表 → 输序号 → 完整文章内容
- ✂️ 自动适配 QQ 消息长度（正文超长自动截断）
